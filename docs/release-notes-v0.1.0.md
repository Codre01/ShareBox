## ShareBox v0.1.0 — Windows

Local Wi‑Fi file sharing for your PC and nearby phones. No cloud, no cables, no phone app.

### Download

1. Download **ShareBox.exe** from the assets below.
2. Double‑click to run (portable — **no installer**).
3. If Windows SmartScreen appears: **More info → Run anyway**.
4. Pair your phone from Control Center (same Wi‑Fi) — [user guide](https://github.com/Bolutifebabs8/ShareBox/blob/master/docs/user-guide.md).

### What’s included

- Windows Control Center + system tray host
- Browser client for phones (pair via QR)
- Shared folder browse / upload / download
- Shared clipboard (trusted devices)
- Device approve / rename / revoke
