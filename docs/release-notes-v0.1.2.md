## ShareBox v0.1.2 — Windows

### What’s new

- **LAN IP only** for connect / QR / Copy link. `sharebox.local` (mDNS) is disabled for now — it was unreliable on Android and caused iOS to treat `.local` and IP as different sites.
- Friendly readable hostnames can return in a later update.

### Download

1. Download **ShareBox.exe** below (replace your previous copy).
2. Double‑click to run (portable — no installer).
3. If SmartScreen appears: **More info → Run anyway**.
