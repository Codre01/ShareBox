## ShareBox v0.1.1 — Windows

### What’s new

- **Copy pairing link** in Control Center — share a LAN link with another PC (or paste into a browser), then approve and name the device on the host as usual. QR pairing for phones is unchanged.

### Download

1. Download **ShareBox.exe** below (replace your previous copy if you already had v0.1.0).
2. Double‑click to run (portable — no installer).
3. If SmartScreen appears: **More info → Run anyway**.
